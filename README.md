# NYC_TowerDefense

Изометрическая браузерная tower defense о караване, который проходит через мистический ночной город. Игрок ставит и улучшает защитные башни, чтобы довести караван через три района.

Проект разрабатывается на [ArcEngine](https://github.com/xaidan777/ArcEngine) (MIT, © 2026 Tearevo). В основе движка — Babylon.js; исходная лицензия сохранена в [LICENSE](LICENSE). Визуальные и игровые элементы этой игры создаются отдельно и не используют материалы Deadlock.

## Состояние

Играбельный прототип: три района, караван, три башни с разными ролями, четыре вида противников и сохранение лучших результатов. Перед публикацией на Яндекс Играх нужны финальные игровые модели, проверка SDK в их консоли и полировка баланса на телефонах.

## Локальный запуск

Нужен Node.js. Запустите `node tools/dev-server.mjs` и откройте адрес, который он выведет. На Windows доступны `run.bat`, `check.bat` и `build.bat`.

Проверка: `node tools/check.mjs`. Сборка архива: `node tools/build.mjs`; ZIP появится в `dist/`.

## План первой версии

- Три района с отдельными маршрутами и точками установки.
- Караван, три типа защитных башен, четыре типа противников, улучшение и продажа башен.
- Управление мышью и касанием, сохранение открытых уровней и лучших результатов.
- Адаптация для Яндекс Игр: SDK, пауза, локализация, готовый ZIP для загрузки в консоль.

Рекламу добавим после проверки игрового цикла.

Референсы chibi-врагов для 3D и требования к игровым сеткам находятся в [references/tripo/README.md](references/tripo/README.md). Бесплатные тестовые модели Tripo допустимы только в некоммерческом прототипе; для выпуска на Яндекс Играх права на модели нужно подтвердить отдельно.
