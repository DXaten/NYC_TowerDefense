# NYC_TowerDefense

«Искра рассвета» — изометрическая браузерная tower defense об инспекторе городских маяков. Игрок сопровождает караван с Искрой через три района мистического индустриального Нью-Йорка: у каждого маяка нужно выдержать последнюю оборону и вернуть свет. История постепенно раскрывает, почему городской туман исказил духов.

Проект разрабатывается на [ArcEngine](https://github.com/xaidan777/ArcEngine) (MIT, © 2026 Tearevo). В основе движка — Babylon.js; исходная лицензия сохранена в [LICENSE](LICENSE). Визуальные и игровые элементы этой игры создаются отдельно и не используют материалы Deadlock.

## Состояние

Играбельный прототип: три района, четыре типа врагов, пять видов башен с разными ролями, колода и случайная рука из трёх карт. Перед боем есть отдельные экраны района и колоды. На телефоне весь маршрут виден в статичном изометрическом ракурсе; башни строятся касанием площадки и улучшаются по типу из нижней панели. Караван зажигает фонари, заряжая «Нить рассвета» для очищающего импульса. У маяка после короткой подготовки враги идут толпой с начала маршрута. Победы открывают башни, улики и выбор постоянной модификации; прогресс и лучшие результаты сохраняются локально.

Перед публикацией на Яндекс Играх нужны финальные игровые модели, проверка работы SDK в консоли площадки, тесты производительности и полировка баланса на телефонах.

## Локальный запуск

Нужен Node.js. Запустите `node tools/dev-server.mjs` и откройте адрес, который он выведет. На Windows доступны `run.bat`, `check.bat` и `build.bat`.

Проверка: `node tools/check.mjs`. Сборка архива: `node tools/build.mjs`; ZIP появится в `dist/`.

## План первой версии

- Три района с отдельными маршрутами, маяками и последней обороной.
- Пять башен, четыре типа противников, колода из трёх или четырёх карт, случайная рука и улучшение всего типа башни во время боя.
- «Нить рассвета»: фонари вдоль пути усиливают ближайшие башни и дают заряд для очищающего импульса.
- Вертикальный интерфейс для телефона и управление мышью на ПК; локальное сохранение открытых уровней, наград и лучших результатов.
- Подготовка к Яндекс Играм: мост SDK, пауза, русский и английский интерфейс, ZIP для загрузки в консоль. Проверка интеграции в самой консоли ещё предстоит.

Рекламу добавим после проверки игрового цикла.
